# 教练教学回顾验收

来源：本会话历史公开行动前缀。由当前 Agent 实际撰写；非独立盲测，未证明策略校准。没有引用实际隐藏底牌或按实际输赢评分。

## 弱牌连续反加

公开证据：翻牌前 Q8 不同花，开池25、再加75后对手反加220

教练分析：倾向弃牌。Q8 容易被继续范围压制，不能假定连续反加者仍会大量弃牌。若没有公开反击过度证据，不继续五次加注。

检查：有具体倾向、证据和取舍；缺失筹码或金额时不编造精确金额。

## 顶对弱踢脚

公开证据：Q7 同花，翻牌 Q63 两方块，单挑

教练分析：小额下注或过牌接近。下注可让部分较小对子和听牌付费；面对大额反加应降低投入，不能把顶对当作打光筹码的理由。

检查：有具体倾向、证据和取舍；缺失筹码或金额时不编造精确金额。

## 坚果听花

公开证据：AQ 持 A黑桃，公共牌 Q红桃、2黑桃、K黑桃、5黑桃；对手下注150，底池465

教练分析：倾向跟注。中对有一定摊牌价值且有坚果同花改善机会；加注可能赶走较弱牌、留下强牌。河牌未改善遭重注需重新判断。

检查：有具体倾向、证据和取舍；缺失筹码或金额时不编造精确金额。

## 多人高牌

公开证据：J8，翻牌356两红桃，五人底池175，前面过牌

教练分析：过牌。多人底池需要同时让多位对手放弃，高牌没有足够价值下注对象。免费观察改善，面对下注通常放弃。

检查：有具体倾向、证据和取舍；缺失筹码或金额时不编造精确金额。

## 单色顶两对

公开证据：AJ方块，翻牌 AJ7全红桃，单挑

教练分析：可小额价值下注或过牌保护范围。两对领先不少单对，但已有同花威胁；大额下注不一定获得更差牌跟注，不能直接全押。

检查：有具体倾向、证据和取舍；缺失筹码或金额时不编造精确金额。

## 河牌抓诈唬

公开证据：AQ持A黑桃，河牌Q2K5三黑桃加9方块，对手转牌主动下注后河牌全押455，底池1070

教练分析：倾向弃牌。门槛约29.8%，需要足够真实诈唬支撑；没有第四张黑桃，A黑桃并未成同花。阻断部分价值不等于自动值得跟注。

检查：有具体倾向、证据和取舍；缺失筹码或金额时不编造精确金额。

## 短码反击

公开证据：96同花开35，短码对手挤压到140，另有跟注者

教练分析：倾向弃牌或谨慎比较跟注。有效筹码降低隐含赔率，不能假定同花牌能靠后续免费发牌实现收益；不靠虚构弃牌率反加。

检查：有具体倾向、证据和取舍；缺失筹码或金额时不编造精确金额。

## 近似选择

公开证据：Q10同花，翻牌79J彩虹，单挑底池180

教练分析：可半池半诈唬，也可过牌。两头顺听牌有改善空间；下注争取立即拿池并保留改善，遭大额反加需按价格重评，不无条件打满。

检查：有具体倾向、证据和取舍；缺失筹码或金额时不编造精确金额。
